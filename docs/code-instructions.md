### Code Style
1) Always follow OOP
2) Code must always be begineer friendly. Easily understandable simple to read.
3) Avoid heavy comments. 
4) Use spaces wherever needed
5) classes ,functions,variable names need to be begineer friendly

### Repo Structure
1) All pydantic schemas are kept in models folder
2) High level features are kept in modules folder
3) utils folder will include common functions and helpers
